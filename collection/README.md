# 🎮 Collection Switch 2

Application mobile (PWA) pour suivre une collection de jeux physiques Switch 2 et trouver les meilleurs prix en France.

- **Catalogue** : jeux avec édition (standard, collector) et support (cartouche complète ou Game-Key Card), chaque info avec sa source.
- **Ma liste** : possédés et souhaits, avec un prix cible.
- **Promos** : prix relevés dans les enseignes françaises (Amazon, Fnac, Micromania, Auchan, Leclerc, Boulanger, Carrefour, Cultura, Cdiscount, Darty — modifiable), triés par prix, baisse ou fraîcheur.
- **Relevés en magasin** : à noter à la main dans la fiche d'un jeu, car aucun site ne les publie.

Les prix viennent de Serper (Google Shopping, version France), avec une clé personnelle stockée uniquement dans le navigateur. Les résultats sont filtrés : Switch 2 uniquement, bonne édition, enseignes choisies, prix plausible.

Installation : menu du navigateur, puis « Ajouter à l'écran d'accueil » ou « Installer l'application ».

Les prix sont indicatifs : toujours vérifier sur le site de l'enseigne avant d'acheter.
